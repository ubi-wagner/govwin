# Architecture Explorer — generator

An interactive, self-contained explorer of the `govtech_intel` schema and its data flows,
rendered to **`docs/architecture/explorer.html`**. Seeded from the real repo: the schema is
introspected from the migrated database (the applied form of `db/migrations/*.sql`), so it stays
truthful as the system grows. Companion to the text source-of-truth `docs/DATA_FLOW.md` and the
live `/admin/workflows` Workflow Map.

## Regenerate (as you go)

```bash
cd frontend
# 1. re-introspect the schema (only needed when tables/columns/FKs changed)
ARCH_DB_URL=postgresql://user@host:5432/govtech_intel node scripts/architecture/extract.mjs
# 2. re-render the explorer (also run this after editing overlay.json)
node scripts/architecture/generate.mjs
```

`ARCH_DB_URL` falls back to `DATABASE_URL`. `extract.mjs` is introspection-only — it reads
`information_schema` and never writes to the database. Point it at any migrated copy (the local
sandbox, a staging DB, etc.).

## Files

| File | Role |
|------|------|
| `extract.mjs` | DB → `model/schema.json` — tables, columns (name/type/nullable/PK), FK edges. |
| `model/schema.json` | The mechanically-extracted schema. Regenerated by `extract.mjs`; committed so the explorer builds without a DB. |
| `overlay.json` | **The hand-authored layer — edit this.** Subsystem grouping rules, the data-flow traces, and the UI→table map. Mirrors `docs/DATA_FLOW.md`. |
| `template.html` | The app shell (CSS + vanilla JS): sidebar, FK-neighborhood graph, fields table, flows + UI views. Model injected at the `/*__ARCH_MODEL__*/` marker. |
| `generate.mjs` | Merges schema + overlay (assigns subsystems, computes FK edges both directions, stamps the migration head) and writes `docs/architecture/explorer.html`. |

## Extending

- **New tables** appear automatically after `extract` + `generate`. If a table lands in the
  **Other** subsystem, add its name (or a prefix) to the right entry in `overlay.json`.
- **New data flow?** Add a trace to `overlay.json → traces` (steps carry an optional `table` so the
  node links into the schema view).
- **New surface?** Add it to `overlay.json → uis`.

The explorer is one self-contained HTML file with no external assets — open it directly, publish it
as an artifact, or serve it statically.
