# UI CANVAS — every overlay layer, on every canvas surface

> Generated by `frontend/scripts/drive-canvas-overlays.mjs`. Images in `docs/ui-canvas/`.
> Regenerate; do not hand-edit.

The canvas is the densest state surface in the product, and every earlier sweep photographed
it once: at rest, overlays off, nothing selected — the one state an author almost never looks
at. The structure they work against is painted by seven togglable layers.

**Each capture is verified twice:** the chip reports `aria-pressed="true"`, AND the canvas
pixels changed against the all-off baseline. A chip that lights up while drawing nothing is
exactly the defect this found (B134), so `aria-pressed` alone is not evidence.

| surface | how it is reached |
|---|---|
| `fluid-document` | the assembled proposal — DEFAULT tab of the workspace. Only surface offering Sections/Groups/Compliance/Budget |
| `proposal-section` | the per-section editor. Omits `Sections` by design: this surface IS one section |
| `blank-letter` · `blank-deck` · `blank-sheet` · `blank-flier` | one canvas per preset, **authored through the product POST** and removed — this fixture stores only `letter`, so a deck and a sheet do not otherwise exist |
