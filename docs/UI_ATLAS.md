# UI ATLAS — every path, photographed

> Images and `index.json` are generated by `frontend/scripts/capture-ui-atlas.mjs` +
> `build-ui-contact-sheets.mjs`; **this prose is generated by `scripts/write-ui-docs.mjs`**
> from those indexes. Do not hand-edit — re-run it.
>
> ⚠️ `--lane X` refreshes ONE lane and MERGES into `index.json`, keeping the other lanes' shots
> and the full-run coverage scalars, and stamping `partialLanes`. It used to REPLACE the file,
> which silently cut `drive-ui-states.mjs` — which reads this index to decide what to drive —
> down to a single lane. That drive now refuses a lane-partial index outright.
>
> **What is committed:** everything — the contact sheets, `index.json`, AND the per-route
> full-page images, deliberately (see the note in `.gitignore`): they are the reviewable
> record of what every screen actually looked like. That record is large — `docs/ui-atlas/`
> is ~100MB of PNG and `docs/ui-states/` ~38MB of JPEG — so a re-run rewrites a lot of
> bytes. Regenerate with:
>
> ```bash
> cd frontend && node scripts/capture-ui-atlas.mjs && node scripts/build-ui-contact-sheets.mjs \
>   && node scripts/write-ui-docs.mjs
> ```
