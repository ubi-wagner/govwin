`docs/UI_ATLAS.md` photographs every page **at rest**. Almost nothing a customer does happens at
rest — and most of it is not a modal either. A tab switches the panel, a filter re-queries the
list, an expander reveals a row, a card selects and swaps the pane beside it.

mobile nav drawer as a real overlay — a state the desktop pass structurally cannot reach.
